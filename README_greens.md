# Equations of motion, Green's functions, and sum rules

SNEG generates the equations of motion of operators, closes them exactly
when the operators generated by repeated commutation with the Hamiltonian
span a finite set, and returns the retarded Green's function and the moments
of the spectral function. For finite fermion systems, exact thermal averages
and the Lehmann representation serve as references.

## Conventions

The retarded Green's function is written in the notation of Zubarev,

$$G_{AB}(z) = \langle\langle A; B\rangle\rangle_z = -i\int_0^\infty dt\,
e^{izt}\langle [A(t), B]_\eta\rangle,\qquad z = \omega + i0^+,$$

with the anticommutator ($\eta = +1$) if $A$ is odd in the fermion operators
and the commutator ($\eta = -1$) otherwise; $\hbar = 1$, $A(t) = e^{iHt} A
e^{-iHt}$. It obeys the equation of motion

$$z\,\langle\langle A; B\rangle\rangle = \langle [A, B]_\eta\rangle +
\langle\langle [A, H]; B\rangle\rangle ,$$

and the spectral function $A_{AB}(\omega) = -\mathrm{Im}\,G_{AB}(\omega +
i0^+)/\pi$ (for $B = A^\dagger$) has the moments (sum rules)

$$\int \omega^n A_{AB}(\omega)\,d\omega = \langle [\mathcal L^n A, B]_\eta
\rangle,\qquad \mathcal L A = [A, H].$$

* `liouvillian[A, H, n]` returns $\{A, \mathcal L A, \dots,
  \mathcal L^n A\}$; symbolic sums are allowed.
* `spectralmoments[A, B, H, n]` returns the moments $k = 0, \dots, n$.
* `eomclosure[A, H]` returns `{{O1, ...}, M, a}`: the distinct operator
  monomials $O_i$ generated from $A = \sum_i a_i O_i$ by repeated commutation
  with $H$, and the matrix $M$ with $[O_i, H] = \sum_j M_{ij} O_j$. If more
  than `"MaxOperators"` (100) monomials are generated, the equations are
  reported as not closed.
* `greensfunction[A, B, H, z]` solves the closed equations,
  $G_{AB}(z) = a\cdot(z - M)^{-1} N$ with $N_i = \langle [O_i, B]_\eta
  \rangle$.

The averages are written as `avg[...]` (as in
[`README_quadratic.md`](README_quadratic.md)), or computed by the function
given with `"Average" -> f`, e.g. `thermalaverage[#, H, modes, T] &` or
`gaussianaverage[#, H, modes, T] &`. The closure and the moments are exact;
no decoupling is applied.

## Examples

The Hubbard atom, $H = \epsilon(n_\uparrow + n_\downarrow) +
U n_\uparrow n_\downarrow$, closes with $d_\uparrow$ and
$d_\uparrow n_\downarrow$:

```wl
Needs["sneg`"]
snegfermionoperators[d]; snegrealconstants[e, U];
H = e (number[d[], UP] + number[d[], DO]) + U nc[number[d[], UP], number[d[], DO]];
greensfunction[d[AN, UP], d[CR, UP], H, z]
(* (1 - <n_dn>)/(z - e) + <n_dn>/(z - e - U), as a single fraction *)
spectralmoments[d[AN, UP], d[CR, UP], H, 2]
(* {1, e + U <n_dn>, e^2 + (2 e U + U^2) <n_dn>} *)
```

A resonant level coupled to two bath levels gives the hybridization function
$\Delta(z) = \sum_k v_k^2/(z - \epsilon_k)$:

```wl
snegfermionoperators[c]; snegrealconstants[e1, e2, v1, v2];
H = e number[d[], UP] + e1 number[c[1], UP] + e2 number[c[2], UP] +
  v1 hop[c[1], d[], UP] + v2 hop[c[2], d[], UP];
greensfunction[d[AN, UP], d[CR, UP], H, z]
(* 1/(z - e - v1^2/(z - e1) - v2^2/(z - e2)) *)
```

For a spin in a field, $H = B S^z$, the bosonic (commutator) function is
`greensfunction[S[1, 4], S[1, 5], B S[1, 3], z]` $= 2\langle S^z\rangle/
(z + B)$.

## Exact references for finite systems

`thermalaverage[X, H, modes, T]` computes $\mathrm{Tr}\,e^{-H/T}X /
\mathrm{Tr}\,e^{-H/T}$ ($T = 0$: ground state, degenerate ground states with
equal weights) and `lehmann[A, B, H, modes, T]` the poles and weights of

$$G_{AB}(z) = \sum_j \frac{w_j}{z - \omega_j},\qquad
w = \langle m|A|n\rangle\langle n|B|m\rangle(\rho_m \pm \rho_n),\quad
\omega = E_n - E_m,$$

by exact diagonalization in the Fock space of the fermion modes (templates as
in `quadraticform`). For the Hubbard dimer the equations of motion of
$c_{1\uparrow}$ close with 22 operators, and

```wl
H = -hop[c[1], c[2]] + 2 Sum[nc[number[c[i], UP], number[c[i], DO]], {i, 2}] - 3/10 Sum[number[c[i]], {i, 2}];
g = greensfunction[c[AN, 1, UP], c[CR, 2, UP], H, z,
  "Average" -> (thermalaverage[#, H, {c[1], c[2]}, 2/5] &)];
l = lehmann[c[AN, 1, UP], c[CR, 2, UP], H, {c[1], c[2]}, 2/5];
(g /. z -> 0.3 + 0.7 I) - Total[l[[All, 2]]/(0.3 + 0.7 I - l[[All, 1]])]   (* ~ 10^-16 *)
```

The moments from `spectralmoments` with the same averages equal
$\sum_j w_j\omega_j^n$.

## Limitations

* The closure is exact; for interacting lattice models the equations of
  motion do not close, and approximations such as Hubbard-I decouplings have
  to be applied to the commutators by hand.
* `eomclosure` and `greensfunction` require explicit modes (no symbolic
  sums); `liouvillian` and `spectralmoments` accept sums.
* `thermalaverage` and `lehmann` work with fermion modes only; their cost
  grows as $2^{2n}$ for $n$ modes (spin included).
