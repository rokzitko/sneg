# quickISObasis

## Usage
- `quickISObasis[{c[1], c[2], ...}]` gives a basis of the Fock space of the spin-1/2 levels `c[1]`, `c[2]`, ... in the creation operator representation, organized in subspaces with well-defined total isospin $I$ and total spin $S$; each subspace contains the states with $I_z = I$ and $S_z = S$.

## Details
- The total isospin is $\mathbf I = \sum_i \mathbf I_i(n_i)$, with $I^z = Q/2 = (N - N_\mathrm{levels})/2$ and $I^+ = \sum_i (-1)^{n_i} c^\dagger_{i\uparrow} c^\dagger_{i\downarrow}$ (see `isospin`). The phase exponent $n_i$ of the level `c[i]` is the value of `nnop[c[i]]`; for a bipartite lattice, it is even on one sublattice and odd on the other.
- `nnop[c[i]]` must be defined for all levels before `quickISObasis` is called (see Possible Issues).
- The result is a list `{{{I, S}, {states}}, ...}`. Each state represents a multiplet of $(2I+1)(2S+1)$ states, obtained by applying $I^-$ and $S^-$; hence $\sum (2I+1)(2S+1)\, d_{I,S} = 4^{N_\mathrm{levels}}$.
- Matrices computed in this basis are the reduced matrices of operators that commute with both $\mathbf S$ and $\mathbf I$, such as the half-filled Hubbard model in the particle-hole symmetric form $H = -t\sum_{\langle ij\rangle\sigma} (c^\dagger_{i\sigma} c_{j\sigma} + \mathrm{h.c.}) + \frac{U}{2} \sum_i (n_i - 1)^2$ on a bipartite lattice, or the particle-hole symmetric Anderson and Kondo impurity models. This $SU(2)_\mathrm{spin} \times SU(2)_\mathrm{isospin}$ symmetry (the `ISO` symmetry type of NRG Ljubljana) reduces the matrix sizes considerably.
- Construction: the $(Q, S)$ basis of `qsbasisvc` is transformed with `transformQStoIS`: starting from the highest charge, the states of each subspace are the isospin highest-weight states with $I = Q/2$; the multiplet partners generated by $I^-$ are projected out of the subspaces with lower $Q$. The result is converted to the creation operator representation.
- `quickISObasis` calls `makebasis` with its argument. Use `bzop2bzvc` to obtain the occupation number representation.
- The subspaces are ordered by decreasing $Q$ of the highest-weight states, not sorted.
- `quickISOSZbasis` gives the $(I, S_z)$ basis, and `quickSU2basis` the basis with isospin only.

## Developer Notes
- `quickISObasis[ops]` is the private function `quickisobasis[ops, qsbasisvc]`, which builds the isospin lowering operator `Total[isospinminus[#, nnop[#]] & /@ ops]` and calls `transformQStoIS`. `quickISOSZbasis` and `quickSU2basis` use `qszbasisvc` and `qbasisvc` instead.
- NRG Ljubljana constructs the `ISO`, `ISOSZ`, and `SU2` bases with the same procedure, with `nnop` defined in the model files (alternating along the Wilson chain), and stores the quantum numbers as $2I+1$, $2S+1$.

## Examples
### Basic Examples
A single level: the empty and doubly occupied states form an isospin doublet, represented by the doubly occupied state, and the singly occupied states form a spin doublet:
```wl
snegfermionoperators[d];
nnop[d[]] = 0;
quickISObasis[{d[]}]
```

### Scope
Two levels with alternating phases:
```wl
snegfermionoperators[c];
nnop[c[1]] = 0; nnop[c[2]] = 1;
bz = quickISObasis[{c[1], c[2]}]
```
Counting the multiplet degeneracies gives the dimension of the Fock space:
```wl
Total[(2 #[[1, 1]] + 1) (2 #[[1, 2]] + 1) Length[#[[2]]] & /@ bz]
```

### Applications
Half-filled Hubbard dimer in the particle-hole symmetric form, $H = -t \sum_\sigma (c^\dagger_{1\sigma} c_{2\sigma} + \mathrm{h.c.}) + \frac{U}{2} \sum_i (n_i - 1)^2$. The largest matrix is $2 \times 2$; the subspace $(I, S) = (0, 0)$ contains the singlet ground state:
```wl
snegfermionoperators[c];
snegrealconstants[t, U];
nnop[c[1]] = 0; nnop[c[2]] = 1;
bz = quickISObasis[{c[1], c[2]}];
makebasis[{c[1], c[2]}];
H = -t hop[c[1], c[2]] + U/2 (isozsq[c[1]] + isozsq[c[2]]);
{First[#], Eigenvalues[Last[#]]} & /@ makematricesbzvc[H, bzop2bzvc[bz]]
```
The Hamiltonian commutes with the total isospin lowering operator:
```wl
Expand[komutator[H, isospinminus[c[1], nnop[c[1]]] + isospinminus[c[2], nnop[c[2]]]]]
```

### Properties & Relations
The states are eigenstates of $\mathbf I^2$ and $\mathbf S^2$:
```wl
snegfermionoperators[c];
nnop[c[1]] = 0; nnop[c[2]] = 1;
bz = bzop2bzvc[quickISObasis[{c[1], c[2]}]];
ii = Last[manyisospin[{c[1], c[2]}, {0, 1}]];
ss = Last[manyspin[{c[1], c[2]}]];
And @@ Flatten[Table[{Expand[ap[ii, v] - sub[[1, 1]] (sub[[1, 1]] + 1) v] === 0, Expand[ap[ss, v] - sub[[1, 2]] (sub[[1, 2]] + 1) v] === 0}, {sub, bz}, {v, sub[[2]]}]]
```
---
The same basis is obtained with `transformQStoIS` and an explicit isospin lowering operator:
```wl
Tm = isospinminus[c[1], 0] + isospinminus[c[2], 1];
Expand[transformQStoIS[qsbasisvc[{c[1], c[2]}], Tm]] === Expand[bzop2bzvc[quickISObasis[{c[1], c[2]}]]]
```

### Possible Issues
The isospin phases determine the basis. With equal phases, $I^+ = \sum_i c^\dagger_{i\uparrow} c^\dagger_{i\downarrow}$, the isospin singlet in the subspace $(0, 0)$ is the antisymmetric combination of the doubly occupied states, $(c^\dagger_{2\downarrow} c^\dagger_{2\uparrow} - c^\dagger_{1\downarrow} c^\dagger_{1\uparrow})|0\rangle/\sqrt 2$; this isospin does not commute with the hopping $\sum_\sigma (c^\dagger_{1\sigma} c_{2\sigma} + \mathrm{h.c.})$:
```wl
snegfermionoperators[c];
nnop[c[1]] = 0; nnop[c[2]] = 0;
Select[quickISObasis[{c[1], c[2]}], First[#] == {0, 0} &]
```
With alternating phases, appropriate for the bipartite dimer, the singlet is the symmetric combination:
```wl
nnop[c[2]] = 1;
Select[quickISObasis[{c[1], c[2]}], First[#] == {0, 0} &]
```
---
If `nnop` is not defined for a level, the code intends to use the phase 0, but in current versions of Mathematica the test `ValueQ[nnop[c[i]]]` gives `True` for declared operators, and the undefined `nnop[c[i]]` enters the basis states, which then cannot be simplified. The result contains `nnop`:
```wl
snegfermionoperators[e];
FreeQ[quickISObasis[{e[]}], nnop]
```
```wl
nnop[e[]] = 0;
FreeQ[quickISObasis[{e[]}], nnop]
```
