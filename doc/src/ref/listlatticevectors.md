# listlatticevectors

## Usage
- `listlatticevectors` is the list of the symbols declared as lattice vectors with `sneglatticevectors`.

## Details
- The list is sorted and is for inspection; the properties are stored with the symbols.

## Examples
### Basic Examples
```wl
sneglatticevectors[a1, a2];
listlatticevectors
```
