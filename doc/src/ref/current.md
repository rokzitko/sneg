# current

## Usage
- `current[a[i], b[j]]` gives the particle-current operator $\sum_\sigma (-i\, a^\dagger_{i\sigma} b_{j\sigma} + i\, b^\dagger_{j\sigma} a_{i\sigma})$ associated with `hop[a[i], b[j]]`.
- `current[a[i], b[j], σ]` gives the current $-i\, a^\dagger_{i\sigma} b_{j\sigma} + i\, b^\dagger_{j\sigma} a_{i\sigma}$ of the spin projection *σ* only.

## Details
- `current[a[i], b[j]]` is $i[\mathrm{hop}(a_i, b_j), n_a]$ with $n_a$ = `number[a[i]]`: it is the rate of change $\dot n_a$ ($\hbar = 1$) generated by the hopping term $+$`hop[a[i], b[j]]`, i.e. the particle current flowing from `b[j]` to `a[i]` for the hopping amplitude $+1$.
- For the hopping term $-t$ `hop[a[i], b[j]]` with real $t$, the particle current from `b[j]` to `a[i]` is $J_{b\to a} = -t$ `current[a[i], b[j]]`. The electric current is obtained by multiplying with the charge of the carriers, $-e$ for electrons.
- `current[a[i], b[j]]` is `currentphi[a[i], b[j], 0]`, which equals `hopphi[a[i], b[j], -Pi/2]`; for hopping terms with a phase, see `currentphi`.
- `current[b[j], a[i]]` is `-current[a[i], b[j]]`.
- The form without *σ* requires spin-1/2 fermions. The levels are given without the creation/annihilation and spin indexes. `current` is not `Listable`.

## Examples
### Basic Examples
Current between two levels:
```wl
snegfermionoperators[a, b];
current[a[], b[]]
```
It is the time derivative of $n_a$ for $H = $ `hop[a[], b[]]`:
```wl
Expand[I komutator[hop[a[], b[]], number[a[]]] - current[a[], b[]]]
```

### Scope
Spin-resolved current:
```wl
snegfermionoperators[d, f];
current[d[], f[0], UP]
```
---
The total current is the sum of the spin-resolved currents:
```wl
Expand[current[d[], f[0]] - current[d[], f[0], UP] - current[d[], f[0], DO]]
```

### Applications
Continuity equation on a four-site chain with the hopping $-t$. The time derivative of the occupancy of each inner site equals the difference between the currents through the two adjacent bonds, $\dot n_j = J_{j-1\to j} - J_{j\to j+1}$ with $J_{j\to j+1} = -t$ `current[c[j + 1], c[j]]`:
```wl
snegfermionoperators[c];
snegrealconstants[t];
H = -t Sum[hop[c[j], c[j + 1]], {j, 3}];
J[i_, j_] := -t current[c[j], c[i]];
Expand[{I komutator[H, number[c[2]]] - (J[1, 2] - J[2, 3]), I komutator[H, number[c[3]]] - (J[2, 3] - J[3, 4])}]
```
The total particle number is conserved:
```wl
Expand[komutator[H, Total[number[{c[1], c[2], c[3], c[4]}]]]]
```
---
Current through a quantum dot coupled to two leads, $H_\mathrm{T} = v_L\, \mathrm{hop}(d, f_L) + v_R\, \mathrm{hop}(d, f_R)$. The current from the left lead into the dot is $v_L\,$`current[d[], fL[]]`, and $\dot n_d$ is the sum of the currents from both leads:
```wl
snegfermionoperators[d, fL, fR];
snegrealconstants[vL, vR];
HT = vL hop[d[], fL[]] + vR hop[d[], fR[]];
Expand[I komutator[HT, number[d[]]] - (vL current[d[], fL[]] + vR current[d[], fR[]])]
```
---
Ground-state expectation value of the bond current in a two-site ring with a flux. The single bond carries the phase $\phi$; the current through it, $-t$ `currentphi[c[1], c[2], φ]`, equals $-\partial E_0/\partial\phi$:
```wl
snegfermionoperators[c];
snegrealconstants[t, phi];
H = -t hopphi[c[1], c[2], phi];
basis = {c[CR, 1, UP], c[CR, 2, UP]};
{vals, vecs} = Eigensystem[matrixrepresentationop[H /. t -> 1, basis]];
j = matrixrepresentationop[-t currentphi[c[1], c[2], phi] /. t -> 1, basis];
Simplify[Table[Conjugate[vecs[[n]]].j.vecs[[n]]/(Conjugate[vecs[[n]]].vecs[[n]]) + D[vals[[n]], phi], {n, 2}], phi ∈ Reals]
```

### Properties & Relations
The current changes sign when the levels are exchanged:
```wl
snegfermionoperators[a, b];
current[a[], b[]] == -current[b[], a[]]
```
---
The current is Hermitian:
```wl
Expand[conj[current[a[], b[]]] - current[a[], b[]]]
```
---
Relation with `currentphi` and `hopphi`:
```wl
{current[a[], b[]] == currentphi[a[], b[], 0], current[a[], b[]] == hopphi[a[], b[], -Pi/2]}
```

### Possible Issues
`current[a, b]` is defined for the hopping amplitude $+1$. For $H = -t$ `hop[a, b]`, the factor $-t$ must be included:
```wl
snegfermionoperators[a, b];
snegrealconstants[t];
Expand[{I komutator[-t hop[a[], b[]], number[a[]]] - current[a[], b[]], I komutator[-t hop[a[], b[]], number[a[]]] + t current[a[], b[]]}]
```
