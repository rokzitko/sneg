# genhop

## Usage
- `genhop[t, a[i], b[j]]` gives the hopping operator $\sum_\sigma (t\, a^\dagger_{i\sigma} b_{j\sigma} + t^*\, b^\dagger_{j\sigma} a_{i\sigma})$ with the complex amplitude *t*.
- `genhop[t, a[i], b[j], σ]` gives $t\, a^\dagger_{i\sigma} b_{j\sigma} + t^*\, b^\dagger_{j\sigma} a_{i\sigma}$ for the spin projection *σ* only.

## Details
- The levels are spin-1/2 fermion levels given without the creation/annihilation and spin indexes, as in `hop`. The form without *σ* requires spin-1/2 fermions; the form with *σ* works for any fermion operators.
- *t* is any scalar. The Hermitian conjugate is formed with `Conjugate[t]`; for constants declared with `snegrealconstants`, `Conjugate[t]` is *t*, and for undeclared symbols it remains `Conjugate[t]`.
- `genhop[t, a[i], b[j]]` creates an electron on `a[i]` with amplitude *t*: the order of the levels matters, `genhop[t, a, b]` equals `genhop[Conjugate[t], b, a]`.
- Special cases: `genhop[1, a, b]` is `hop[a, b]`, `genhop[Exp[I φ], a, b]` is `hopphi[a, b, φ]`, and `genhop[t, a, b]` equals `matrixhop[t IdentityMatrix[2], a, b]`.
- In Hamiltonians, a hopping integral $t$ with the usual sign enters as `genhop[-t, a, b]`. Gauge-invariant quantities depend on the phases of the amplitudes only through the sums of phases around closed loops (magnetic flux) and through the phases relative to superconducting order parameters.
- The particle current from `b[j]` to `a[i]` generated by `genhop[t, a[i], b[j]]` is $i[H, n_a]$ = `genhop[-I t, a[i], b[j]]`, i.e. $-i t\, a^\dagger b + i t^* b^\dagger a$.
- `genhop` is not `Listable`. Bare symbols and abstract orbitals (pure functions) are not supported as levels; use `hop` or `matrixhop` for abstract orbitals.

## Examples
### Basic Examples
Hopping with a complex amplitude:
```wl
snegfermionoperators[a, b];
snegcomplexconstants[z];
genhop[z, a[], b[]]
```
Spin-down part only:
```wl
genhop[z, a[], b[], DO]
```

### Scope
Real amplitudes declared with `snegrealconstants`:
```wl
snegfermionoperators[d, f];
snegrealconstants[v];
genhop[v, f[0], d[]]
```
---
Spin-dependent complex amplitudes, as for a junction with spin-orbit coupling in the tunneling region:
```wl
snegfermionoperators[f];
snegrealconstants[w, ws, phi];
genhop[(w + I ws) Exp[-I phi/2], f[1], f[2], UP] + genhop[(w - I ws) Exp[-I phi/2], f[1], f[2], DO]
```

### Applications
Particle current. For $H = $ `genhop[t, a, b]`, the current into `a` is $\dot n_a = i[H, n_a]$:
```wl
snegfermionoperators[a, b];
snegcomplexconstants[z];
Expand[I komutator[genhop[z, a[], b[]], number[a[]]] - genhop[-I z, a[], b[]]]
```
---
Aharonov-Bohm flux through a triangle. Only the total phase of the three amplitudes enters the spectrum. With the phase $\phi$ on a single bond, the characteristic polynomial of the single-particle Hamiltonian depends on $\phi$ only through $\cos\phi$:
```wl
snegfermionoperators[c];
snegrealconstants[t, phi];
H = genhop[-t Exp[I phi], c[1], c[2]] + genhop[-t, c[2], c[3]] + genhop[-t, c[3], c[1]];
Simplify[ExpToTrig[CharacteristicPolynomial[matrixrepresentationop[H, Table[c[CR, j, UP], {j, 3}]], x]]]
```
The same polynomial is obtained with the phase $\phi/3$ on each of the three bonds:
```wl
H = Sum[genhop[-t Exp[I phi/3], c[j], c[Mod[j, 3] + 1]], {j, 3}];
Simplify[ExpToTrig[CharacteristicPolynomial[matrixrepresentationop[H, Table[c[CR, j, UP], {j, 3}]], x]]]
```

### Properties & Relations
`genhop` is Hermitian:
```wl
snegfermionoperators[a, b];
snegcomplexconstants[z];
Expand[conj[genhop[z, a[], b[]]] - genhop[z, a[], b[]]]
```
---
Exchanging the levels conjugates the amplitude:
```wl
Expand[genhop[z, a[], b[]] - genhop[Conjugate[z], b[], a[]]]
```
---
Special cases:
```wl
snegrealconstants[phi];
{genhop[1, a[], b[]] == hop[a[], b[]], genhop[Exp[I phi], a[], b[]] == hopphi[a[], b[], phi], genhop[z, a[], b[]] == matrixhop[z IdentityMatrix[2], a[], b[]]}
```

### Possible Issues
Without *σ*, the levels must be spin-1/2 fermions, and bare symbols are not accepted:
```wl
snegfermionoperators[a, b];
genhop[2, a, b]
```
