# bzvc2bzop

## Usage
- `bzvc2bzop[bz]` converts the basis *bz* from the occupation number representation to the creation operator representation.

## Details
- *bz* is a basis `{{qn, states}, ...}` (see `makematricesbzvc`). Each state is converted with `vc2ops`: `vc[n1, n2, ...]` becomes the product of the creation operators of the occupied states in the order of the global list `BASIS`, $(c^\dagger_1)^{n_1} (c^\dagger_2)^{n_2} \cdots$, with the vacuum implied, and `vc[0, 0, ...]` becomes `1`. The quantum numbers are unchanged.
- Kets at the end of a vector, `vc[n1, ..., ket[k]]`, become `nc[..., ket[k]]`.
- The conversion uses the current `BASIS`; vectors of a different length give the message `vc2ops::incom`.
- `bzop2bzvc` is the inverse conversion. Both representations give the same matrices: `makematricesbzop[op, bzvc2bzop[bz]]` equals `makematricesbzvc[op, bz]`.
- The creation operator representation is convenient for symbolic manipulation, e.g. substitution of operators in `transformtoLR`, and for display. The occupation number representation is faster for matrix calculations.

## Examples
### Basic Examples
The $(Q, S_z)$ basis of a single level in both representations:
```wl
snegfermionoperators[d];
bz = qszbasisvc[{d[]}]
```
```wl
bzvc2bzop[bz]
```

### Scope
The singlet and triplet states of two levels in the $(Q, S)$ basis:
```wl
snegfermionoperators[c];
Cases[bzvc2bzop[qsbasisvc[{c[1], c[2]}]], {{0, _}, _}]
```
---
States with phonon kets:
```wl
snegfermionoperators[d];
bzvc2bzop[transformtoPH[qszbasisvc[{d[]}], {1}]]
```

### Properties & Relations
`bzvc2bzop` gives the basis generated by `qszbasis` directly in the creation operator representation:
```wl
snegfermionoperators[c];
bzvc2bzop[qszbasisvc[{c[1], c[2]}]] === qszbasis[{c[1], c[2]}]
```
---
`bzop2bzvc` is the inverse conversion:
```wl
bz = qsbasisvc[{c[1], c[2]}];
Expand[bzop2bzvc[bzvc2bzop[bz]]] === Expand[bz]
```
